# Superheroes

Activity 8 - Laravel 7 CRUD based on the class Student CRUD example.

Fields: real_name, hero_name, photo (image URL), description.

Configure `.env` with a MySQL database named `superheroes`, run `composer install`, `php artisan key:generate`, `php artisan migrate`, then `php artisan serve`. If frontend assets need rebuilding, run `npm install` and `npm run dev`.

Open `/superhero` to create, view, edit, and delete superheroes.
